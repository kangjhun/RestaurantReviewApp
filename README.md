# RestaurantReviewApp

### Android 기반 개인 맛집 리뷰 기록 애플리케이션

사용자가 방문한 음식점의 정보를 등록하고, 리뷰와 별점을 기록하여 지도 기반으로 관리할 수 있는 Android 애플리케이션입니다.

광고성 리뷰나 추천 중심의 서비스와 달리, **사용자 본인의 음식점 방문 경험을 기록하고 관리하는 것**을 목적으로 개발했습니다.

## 2. 주요 기능

### ① 음식점 리뷰 등록

- 음식점 이름, 카테고리, 주소, 리뷰 내용 입력
- RatingBar를 이용한 1~5점 별점 등록
- 필수 입력 항목 검사
- Geocoder를 활용한 주소 유효성 확인
- JSP 서버에 HTTP POST 요청을 전송하여 MySQL에 리뷰 저장

### ② 음식점 리뷰 수정

- 기존에 등록한 음식점 정보 및 리뷰 표시
- 리뷰 내용과 별점 수정
- Google Maps를 이용한 음식점 위치 표시
- 수정된 정보를 JSP 서버에 전송하여 데이터베이스 갱신

### ③ 음식점 검색

- 음식점 이름 및 카테고리 기반 검색
- 검색어 자동완성 지원
- 검색 결과를 목록으로 표시
- 선택한 음식점의 리뷰 화면으로 이동

### ④ 지도 기반 리뷰 관리

- Google Maps를 활용한 음식점 위치 표시
- 사용자 현재 위치 기반 지도 이동
- 음식점 위치를 마커로 표시
- 리뷰 등록 및 수정 후 지도와 목록 갱신

## 5. 주요 클래스

| 클래스 | 역할 |
|---|---|
| `MainActivity` | 지도 표시, 검색, 리뷰 목록 관리 |

## 6. 데이터베이스 설계

**Review 테이블**

| 필드 | 설명 |
|---|---|
| ReviewID | 리뷰 고유 식별자 (PK) |
| RestaurantName | 음식점 이름 |
| CategoryName | 음식점 카테고리 |

## 7. 개발 과정 및 문제 해결

### 검색창 초기화 과정에서 발생한 Stack Overflow

**문제**

검색 결과를 초기화하는 과정에서 `search_view.setQuery("", false)`가 반복 호출되어 무한 재귀와 Stack Overflow가 발생했습니다.

**해결**

검색창의 텍스트가 이미 비어 있는 경우에는 `setQuery()`를 다시 호출하지 않도록 조건을 추가하여 반복 호출 문제를 해결했습니다.

### JSP 서버의 JSON 응답 형식 오류

**문제**

MySQL 검색 결과를 JSON 문자열로 변환하는 과정에서 특수문자 이스케이프 및 JSON 배열 형식 문제가 발생했습니다.

**해결**

StringBuilder를 활용하여 JSON 응답 문자열을 구성하고, 이스케이프 처리를 적용하여 응답 형식을 수정했습니다.
